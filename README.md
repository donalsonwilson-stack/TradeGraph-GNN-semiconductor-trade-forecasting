# Learning Global Semiconductor Market Dynamics from International Trade Networks using Hybrid Graph Neural Networks

This repository contains the source code, Jupyter notebooks, and supplementary materials associated with the research paper:

**"Learning Global Semiconductor Market Dynamics from International Trade Networks using Hybrid Graph Neural Networks"**

It was created to ensure the reproducibility of the experiments presented in the paper.

## Repository Structure

- `Primarily graph analysis/` : Preliminary analysis of the global semiconductor trade network.
- `Community detection/` : Louvain community detection and network visualization.
- `Semiconductor trade flow forecasting/` : Implementation of GCN, GraphSAGE, GAT, and the proposed **TradeGraph** model for bilateral trade flow forecasting.
- `Data Link/` : Information and links to the BACI dataset used in this study.

## Dataset

This work uses the **BACI International Trade Database (202601 release)** developed by CEPII.
